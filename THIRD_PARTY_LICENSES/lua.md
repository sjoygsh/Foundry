# Lua

- **Version:** 5.5.1
- **Upstream:** https://www.lua.org/ftp/lua-5.5.1.tar.gz
- **License:** MIT
- **Distribution:** distributed
- **Location in tree:** fetched via build.zig.zon
- **Why we depend on it:** Lua is the pinned, embeddable scripting runtime for M8. Foundry compiles the interpreter directly and links only the core needed by its private host bridge.
- **Modifications:** none
